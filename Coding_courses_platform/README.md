# Coding Courses Platform Website

A simple multi-page **coding education platform website** built using **HTML and CSS**.

This project was created as an early web development project while learning the fundamentals of building websites, creating layouts, styling pages, and connecting multiple HTML pages together.

## 🛠️ Technologies Used

* **HTML5** — for creating the structure and pages
* **CSS3** — for styling, layout, and responsiveness
* **Remix Icon** — for UI icons

## 🚀 How to Run

No installation or external dependencies are required.

### 1. Clone the repository

```bash
git clone https://github.com/gaugit123/Coding_courses_platform.git
cd Coding_courses_platform
```

### 2. Open the project

Open `index.html` in your web browser.

You can also use **VS Code with Live Server** to run the project locally.
